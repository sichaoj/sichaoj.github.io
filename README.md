# Sichao Jiang personal website

This static site mirrors the public Google Site at https://sites.google.com/view/sichaoj: Home, Resources, CV, Research, and Teaching. It includes the original headshot, page copy, two research charts, and local copies of the three PDFs originally stored on the `gh-pages` branch of `sichaoj/personal-website`.

To publish at `https://sichaoj.github.io/`, create a public repository named `sichaoj.github.io`, place all HTML, CSS, and JS files at its root, and set Pages to deploy from the repository branch containing them.

Update page text and document links in the relevant HTML page; update colors and layout in `styles.css`. Google Sites edits do not sync automatically to this site.
